Overview

What is this?

A private fantasy tournament tracker built for 8 friends to compete across the 2026 FIFA World Cup. Each owner is randomly assigned 6 teams from a pot-based draft. Points accumulate from match results and knockout round advancement throughout the tournament.

Tech Stack

React 18 TypeScript Supabase TanStack Query Tailwind CSS Vite

All stats are computed client-side in real time from raw match data stored in Supabase — no server-side recalculation needed. Admins enter scores through the web UI; standings update instantly.

Points Scoring System

Match Points (Group & Knockout)

  • Win (90 min): 3 pts
  • Win (AET/Pen): 2 pts
  • Loss (AET/Pen): 1 pt
  • Loss (90 min): 0 pts
  • Draw (group): 1 pt each
  • Goals: +0.1 per goal scored

Pot Difference Multiplier

Lower-ranked team receives a multiplier on their match points (base + goals) when beating a higher-ranked team:

  • 1 pot difference → ×1.2
  • 2 pot difference → ×1.4
  • 3 pot difference → ×1.6
  • 4 pot difference → ×1.8
  • 5 pot difference → ×2.0

Round Points (Knockout)

Admin manually ticks each round a team reaches. Each tick = +1 Round Point:

  • Round of 32 → 1 pt
  • Round of 16 → 2 pts total
  • Quarterfinals → 3 pts total
  • Semifinals → 4 pts total
  • Final → 5 pts total
  • Winner → 6 pts total
Total Points = Match Points + Round Points   |   Ranking: Total Pts → Goal Difference → Goals Scored   |   Example: Pot 6 beats Pot 3 → (3 + 0.1) × 1.6 = 4.96 pts
